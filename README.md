# Mayank Gaming AI — Vercel-ready

## Free deployment route (subject to provider limits)
1. Create a GitHub repository and upload the contents of this folder (not the ZIP file itself).
2. Import that repository into Vercel.
3. In Vercel Project Settings → Environment Variables, add `OPENAI_API_KEY` with a NEW secret key. Optionally add `OPENAI_MODEL` = `gpt-4.1-mini`.
4. Deploy. Vercel will serve the PWA and the `/api/chat` serverless function.
5. Open the deployed HTTPS URL on Android Chrome. Use Chrome menu → Add to Home screen / Install app.

## Important
- Never put API keys in `public/`, frontend JavaScript, GitHub, screenshots, or chat.
- Revoke any key previously shared in a chat and create a new one.
- OpenAI API usage is billed separately from ChatGPT. Hosting free tiers have limits and can change.
- The APK is not generated by this project. First deploy and install as a PWA; a native APK wrapper is a separate optional step.
